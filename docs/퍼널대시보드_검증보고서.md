## 3. 결함 상세

### 3-1. [결함 1] 100% 초과 전환율 경고 조건 — 브랜드 전체에 미적용

경고 조건이 `모델 필터가 걸려 있고 + 비율이 100% 초과`로 되어 있어, **브랜드 전체 화면에서는 100%를 넘어도 경고가 뜨지 않습니다.**

실제로 **토요타 브랜드 전체 시승→계약 최근3개월평균이 127.6%**로 그대로 표시됩니다. 렉서스도 94.7~96.7%로 100% 문턱에 붙어 있습니다.

원인은 모델 태깅률 차이가 아니라 **시승 집합과 계약 집합이 애초에 겹치지 않는다**는 데 있습니다:

- 렉서스 계약 10,491건 중 시승 기회와 실제로 연결된 건 **2,461건(23.5%)**
- 토요타 계약 8,946건 중 **2,037건(22.8%)**

즉 시승 11,088건과 계약 10,429건은 크기만 비슷할 뿐 **약 77%가 서로 다른 건**입니다. 이 둘을 나눈 값은 전환율이 아니며, 100%를 넘는 것이 정상입니다.

> **조치** — 경고 조건에서 모델 필터 조건을 제거해 브랜드 전체에도 적용하고, 시승→계약 지표에는 실연결률(23.5%)을 병기하거나 지표를 연결 기반으로 재정의합니다.

### 3-2. [결함 2] 데이터 정의 주석 ⑥ 문구가 정의서와 반대

정의서 3-1은 명확합니다:

> ※ 관계형성소개는 관계형성활동에 속하며 SC활동이 아닙니다 (초기 설계 오류가 있었던 부분이므로 특히 주의).

**집계는 이 규칙을 정확히 따르고 있습니다.** 문제는 화면 문구입니다.

주석 ⑥은 2026-07-22 협의 당시의 옛 정의(정의서가 "초기 설계 오류"로 지목한 그 정의)가 남은 것으로 보입니다. 이 문구를 믿고 SC활동 숫자를 인용하면 아래만큼 어긋납니다.

### 3-3. [결함 3] 퍼널 계약 10,429 vs 모델별 계약 10,491

정의서 3-5는 *"채널 합계 = 카테고리 합계 = 딜러 합계 = 전체 총계가 항상 정확히 일치해야 하며, 깨지면 파이프라인 버그로 간주"* 라고 규정합니다.

현재 채널·카테고리·딜러 합계는 서로 **10,429**로 일치하지만, 모델별 계약 차트 합계는 **10,491**입니다(미귀속 62건 차이, 0.6%). 정의서가 같은 문단에서 "미귀속분은 채널집계에서 제외하되 전체 총계에는 포함"이라고도 적고 있어 **정의서 자체가 모순**입니다. 자동화 시 정합성 검증에서 반드시 걸리는 지점입니다.

> **조치** — 정의서 3-5를 "채널·카테고리·딜러 합계는 서로 일치하며, 전체 총계와는 미귀속분만큼 차이가 난다(그 값을 화면에 표기한다)"로 정정하고, 대시보드에도 62건을 명시.

### 3-4. [결함 4] "기회 기준 태깅률" 라벨

화면 문구는 *"기회 기준 태깅률 : 68.1% — 활동 전체가 아닌 '기회'만 놓고 보면 **실제 태깅 성과**입니다"* 입니다.

이 68.1%는 정의서 3-3의 백필(계약모델·시승모델 역보완)을 거친 값입니다. `관심모델(기회)`이 실제 입력된 비율은 **52.0%**(렉서스 18,789 / 36,138)이고, 토요타는 **55.9%**입니다. 백필 자체는 정의서대로이나, "실제 태깅 성과"라는 표현은 SC 입력 규율 지표로 오독됩니다.

> **조치** — "역보완 후 모델 식별률 68.1% (원입력 52.0%)"처럼 두 값을 병기.

## 4. 지표 해석 시 유의점 (결함 아님)

**① 모델별 활동 수치는 백필 방식에 민감합니다.** RAV4 5→6월 활동은 관심모델 원값 기준 **530→1,122(+112%)**, 정의서 3-3 백필 기준 **555→1,749(+215%)**입니다. 보고서의 "3배 급증(+215.3%)"은 백필 기준값이며, 방향성은 두 기준 모두 같으나 배수를 인용할 때는 기준 명시가 필요합니다. 백필이 계약모델을 소스로 쓰므로, **계약이 많이 난 모델에 활동이 더 붙는 성질**이 있어 "활동 증가 → 계약 증가" 인과 서술에는 주의가 필요합니다.

**② 계약은 Gross(정의서 3-2)** 입니다 — 취소 1,425건(13.6%) 포함. 통상 Net 기준인 타겟 달성률과 직접 비교하면 기준이 어긋납니다.

**③ 토요타 5월은 이상치**입니다. 계약 2,315건으로 타 월(847~1,525)의 약 2배입니다. 5월을 기준월로 삼은 증감률은 하락폭이 과장됩니다.

## 5. 제공 자료로 재현되지 않는 항목 — 보고서 「7월 진척도-퍼널 통합분석」

대시보드가 아니라 **보고서 docx 쪽** 문제입니다.

**① 타겟 달성률 (3-1 / 4-1 표 전체)** — 계약추이 엑셀에 목표 컬럼이 없어 재현 불가입니다. 역산하면 렉서스 RX 목표가 1월 148 → 5월 409로 2.8배 변동합니다. 같은 기간 **RX 실계약은 285 → 279건으로 거의 평평**한데 달성률만 192.6% → 70.5%로 하락합니다 — "RX 6개월 연속 부진"은 타겟 상향의 결과일 가능성이 큽니다. 7월분은 계약추이가 7/20까지라 부분월이며, 역산한 7월 목표/6월 목표 비율이 모델마다 0.43~0.57로 제각각이라 일관된 규칙이 없습니다.

**② 딜러별 채널 증감률** — 대시보드에 딜러×채널 교차집계가 없습니다(딜러는 독립 집계). "용산 -55%, 부산 -50%"는 산출 근거가 없고, 대시보드의 RX 딜러별 활동으로 계산하면 **용산 -32.7%, 부산 -26.4%**입니다. "인천 견조"도 실제로는 27→23건(-14.8%) 감소이며, 토요타 CROWN은 "분당 -47%" → 실제 **-40.9%**, "대전 견조" → 실제 **-7.1% 감소**, 하락 딜러는 6개가 아니라 **7개**입니다.

**③ 예상치끼리 나눈 비율** — 대시보드는 *"숫자는 예상치, 비율은 ~7/26 실측 그대로"*를 명시합니다. 보고서의 시승→계약(RX 68.7%, NX 84.6%, UX 65.5%)은 **예상 계약 ÷ 예상 시승**입니다(대시보드 실측값은 66.7% / 81.2% / 65.0%).
