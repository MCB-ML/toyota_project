# 인증 리포트의 원본 GOLD

여기 있는 파일은 **실행되지 않는다.** 등록 SQL(`../sql/`)이 원본에서 얼마나 달라졌는지
대조하는 용도다 — 계약의 `deviations`에 적은 것 외의 수정이 섞이면 테스트가 잡아낸다.

`reports.test.js`의 "등록 SQL이 GOLD 원문과 일치한다" 묶음이 이 파일을 읽는다.

## 왜 원본을 따로 두나

이 계층의 전제는 "GOLD를 분해하지 않고 그대로 실행한다"이다. 그런데 파라미터 바인딩·
주석 닫기·NULL 가드처럼 실행에 꼭 필요한 수정은 불가피하게 들어간다. 원본이 없으면
"어디까지가 허용된 편차인지"를 확인할 방법이 사라진다.

## 줄바꿈 주의

계약의 `source.sha256`은 이 파일을 **있는 그대로**(CRLF 포함) 읽은 해시다.
편집기가 줄바꿈을 바꾸면 해시가 어긋나 테스트가 깨진다 — 내용을 손대지 말 것.

(`docs/ktws_측정값_쿼리화.xlsx`, 계약의 `source.workbook`/`sheet`/`no` 참고).
