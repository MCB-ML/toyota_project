# 활동_실적 쿼리 규칙

이 topic의 쿼리 패턴은 `ktws_측정값_쿼리화.xlsx`(1-1, 1-2 시트)의 GOLD 쿼리에서 그대로 가져온 것이다 — 추측이 아니라 검증된 정답 SQL이므로, 아래 패턴과 다른 형태로 활동/목표/진행률을 계산하지 말 것.

## 테이블
- `FCT_ACTIVITY_v2` — 활동 실적(act_pk 단위). "활동 건수"는 `cnt`, "실적 건수"는 `actual_cnt`를 SUM.
- `FCT_CRM_TARGET_D` — 활동 목표(day_seq 단위). "목표 건수"는 `target_cnt`를 SUM.
- `DIM_MNG_USER` — 담당 SC/딜러/지점명, 재직 상태, 창구SC 여부.
- `DIM_MNG_DEALER` — 딜러 단위 필터(dealer_id).
- `DIM_CRM_ACT_TYPE`(+`DIM_CRM_ACT_TYPE_ORDER`) — 활동유형 상위카테고리(연락/방문/소개 등).
- `DIM_CALENDAR_KTWS` — 날짜 차원.

## 반드시 포함해야 하는 필터 ("페이지 기본 조건")
활동/목표 건수를 집계하는 질문이면 사용자가 명시적으로 말하지 않아도 아래 4개를 **항상** 포함한다 — 빠지면 정답과 크게 달라진다(실측: 이 필터 없이 계산하면 9,352건, 있으면 정답에 근접):
```sql
AND B.tp_grp_1 IN ('관계형성', '기회창출')                 -- 활동유형 대분류 제한
AND D.facade_sc_yn != '창구SC'                              -- 창구SC 제외
AND D.name NOT IN ('고객지원팀', 'TOYOTA YM')                -- 특정 조직 제외
AND D.user_id NOT IN ('EXCLUDED_USER_ID', 'EXCLUDED_USER_ID', 'EXCLUDED_USER_ID', 'EXCLUDED_USER_ID', 'EXCLUDED_USER_ID', 'EXCLUDED_USER_ID')  -- 특정 사용자 제외
```
(`B`/`D`는 아래 패턴의 별칭 — 실제 쿼리에서 `DIM_CRM_ACT_TYPE`/`DIM_MNG_USER` 별칭에 맞게 바꿀 것)

사용자가 명시한 조건(연월, 재직여부, 딜러, 브랜드, 그룹/부서, 활동유형 세부구분)은 그 위에 추가로 붙인다 — GOLD 쿼리(엑셀 DECLARE 블록)가 지원하는 슬라이서는 이 6개다:
```sql
AND C.YearMonth = '2026-04'      -- 날짜 필터 (사용자가 언급한 연월)
AND D.active_yn = '재직'          -- 재직 여부 (기본값 '재직' — 사용자가 퇴사자도 포함해달라 하지 않는 한)
AND E.dealer_nm = '렉서스 강남'   -- 딜러 필터 (사용자가 언급한 딜러/지점명 — dealer_id가 아니라 dealer_nm 매칭이 더 안정적)
AND D.BRAND = 'LEXUS'            -- 브랜드 필터 (LEXUS/TOYOTA 등 — 사용자가 브랜드를 언급했을 때만)
AND D.group_name = '렉서스 강서'  -- 그룹(지역) 필터
AND D.dept_nm = '강서영업팀'      -- 부서(팀) 필터
-- AND F.common_tp_nm = '잠재고객' -- 활동유형 세부값으로 더 좁힐 때만 (선택)
```
(딜러는 `dealer_id`가 아니라 `dealer_nm`으로 매칭하는 GOLD 쿼리도 있다 — 사용자가 딜러명을 자연어로 말하면 `dealer_nm`을 쓰는 게 더 안전하다.)

## GOLD 쿼리 패턴

### 1. 활동 건수 (act_mtd_(ac)_preOp)
```sql
SELECT SUM(actual_cnt) AS cnt
FROM ktws.FCT_ACTIVITY_v2 AS A
    INNER JOIN ktws.DIM_CRM_ACT_TYPE AS B ON A.tp_key = B.tp_key
    INNER JOIN ktws.DIM_CALENDAR_KTWS AS C ON A.act_dt_fr = C.Date
    INNER JOIN ktws.DIM_MNG_USER AS D ON A.sc_key = D.sc_key
    INNER JOIN ktws.DIM_MNG_DEALER AS E ON D.dealer_key = E.dealer_key
    INNER JOIN ktws.DIM_CRM_ACT_TYPE_ORDER AS F ON B.common_tp_nm = F.common_tp_nm
WHERE C.YearMonth = '2026-04'
  AND D.active_yn = '재직'
  AND E.dealer_id = 'DT00000'
  AND B.tp_grp_1 IN ('관계형성', '기회창출')
  AND D.facade_sc_yn != '창구SC'
  AND D.name NOT IN ('고객지원팀', 'TOYOTA YM')
  AND D.user_id NOT IN ('EXCLUDED_USER_ID', 'EXCLUDED_USER_ID', 'EXCLUDED_USER_ID', 'EXCLUDED_USER_ID', 'EXCLUDED_USER_ID', 'EXCLUDED_USER_ID')
```

### 2. 당월목표 (act_mtd_(target)_preOp)
위 쿼리와 완전히 동일한 구조 — `FCT_ACTIVITY_v2`/`actual_cnt`/`A.tp_key`/`A.act_dt_fr` 대신 `FCT_CRM_TARGET_D`/`target_cnt`/`A.type_cd`/`A.daily_dt`만 바꾼다:
```sql
SELECT SUM(target_cnt) AS cnt
FROM ktws.FCT_CRM_TARGET_D AS A
    INNER JOIN ktws.DIM_CRM_ACT_TYPE AS B ON A.type_cd = B.tp_key
    INNER JOIN ktws.DIM_CALENDAR_KTWS AS C ON A.daily_dt = C.Date
    INNER JOIN ktws.DIM_MNG_USER AS D ON A.sc_key = D.sc_key
    INNER JOIN ktws.DIM_MNG_DEALER AS E ON D.dealer_key = E.dealer_key
    INNER JOIN ktws.DIM_CRM_ACT_TYPE_ORDER AS F ON B.common_tp_nm = F.common_tp_nm
WHERE C.YearMonth = '2026-04'
  AND D.active_yn = '재직'
  AND E.dealer_id = 'DT00000'
  AND B.tp_grp_1 IN ('관계형성', '기회창출')
  AND D.facade_sc_yn != '창구SC'
  AND D.name NOT IN ('고객지원팀', 'TOYOTA YM')
  AND D.user_id NOT IN ('EXCLUDED_USER_ID', 'EXCLUDED_USER_ID', 'EXCLUDED_USER_ID', 'EXCLUDED_USER_ID', 'EXCLUDED_USER_ID', 'EXCLUDED_USER_ID')
```

### 3. 진행률 (실적/목표, %)
목표·실적을 같은 필터로 각각 CTE로 구해 나눈다:
```sql
WITH filtered_dates AS (
    SELECT Date FROM ktws.DIM_CALENDAR_KTWS WHERE YearMonth = '2026-04'
),
filtered_users AS (
    SELECT D.sc_key
    FROM ktws.DIM_MNG_USER AS D
    INNER JOIN ktws.DIM_MNG_DEALER AS E ON D.dealer_key = E.dealer_key
    WHERE D.active_yn = '재직'
      AND E.dealer_id = 'DT00000'
      AND D.facade_sc_yn <> '창구SC'
      AND D.name NOT IN ('고객지원팀', 'TOYOTA YM')
      AND D.user_id NOT IN ('EXCLUDED_USER_ID', 'EXCLUDED_USER_ID', 'EXCLUDED_USER_ID', 'EXCLUDED_USER_ID', 'EXCLUDED_USER_ID', 'EXCLUDED_USER_ID')
),
filtered_types AS (
    SELECT B.tp_key FROM ktws.DIM_CRM_ACT_TYPE AS B WHERE B.tp_grp_1 IN ('관계형성', '기회창출')
),
target_cnt AS (
    SELECT SUM(A.target_cnt) AS cnt
    FROM ktws.FCT_CRM_TARGET_D AS A
    INNER JOIN filtered_dates AS C ON A.daily_dt = C.Date
    INNER JOIN filtered_users AS D ON A.sc_key = D.sc_key
    INNER JOIN filtered_types AS B ON A.type_cd = B.tp_key
),
actual_cnt AS (
    SELECT SUM(A.actual_cnt) AS cnt
    FROM ktws.FCT_ACTIVITY_v2 AS A
    INNER JOIN filtered_dates AS C ON A.act_dt_fr = C.Date
    INNER JOIN filtered_users AS D ON A.sc_key = D.sc_key
    INNER JOIN filtered_types AS B ON A.tp_key = B.tp_key
)
SELECT FORMAT(CAST(A.cnt AS FLOAT) / NULLIF(T.cnt, 0), '0%') AS Percentage
FROM target_cnt AS T CROSS JOIN actual_cnt AS A
```

### 4/5. 목록형(딜러·지점·부서·SC·활동유형별 breakdown) — "활동 목표" / "활동 실적"
위 1/2번이 "합계 1개 값"이라면, 이건 딜러/지점/부서/SC/활동유형카테고리별로 **행을 나눠 보여주는** 버전이다. 필터는 동일(페이지 기본 조건)하지만 연월/딜러 등 슬라이서는 기본적으로 없음(전체 기간·전체 딜러) — 사용자가 지정하면 주석 처리된 조건을 활성화한다. `DIM_MNG_DEALER`는 `LEFT JOIN`이다(딜러가 없는 SC도 결과에 포함):
```sql
-- 활동 실적 (목록형) — 활동 목표는 FCT_CRM_TARGET_D/target_cnt/daily_dt/type_cd로 동일하게 바꾸면 됨
SELECT
    d.dealer_nm, u.group_name, u.dept_nm, u.[name], o.common_tp_nm,
    SUM(f.actual_cnt) AS act_mtd_ac
FROM ktws.FCT_ACTIVITY_v2 AS f
    INNER JOIN ktws.DIM_CALENDAR_KTWS AS c ON f.act_dt_fr = c.[Date]
    INNER JOIN ktws.DIM_CRM_ACT_TYPE AS t ON f.tp_key = t.tp_key
    INNER JOIN ktws.DIM_CRM_ACT_TYPE_ORDER AS o ON t.common_tp_nm = o.common_tp_nm
    INNER JOIN ktws.DIM_MNG_USER AS u ON f.sc_key = u.sc_key
    LEFT JOIN ktws.DIM_MNG_DEALER AS d ON u.dealer_key = d.dealer_key
WHERE t.tp_grp_1 IN (N'관계형성', N'기회창출')
  AND (u.facade_sc_yn <> N'창구SC' OR u.facade_sc_yn IS NULL)
  AND (u.[name] NOT IN (N'고객지원팀', N'TOYOTA YM') OR u.[name] IS NULL)
--  AND c.[Year] = 2026 AND c.[MonthNumber] = 4   -- 연월 지정 시
--  AND d.dealer_nm = '렉서스 강남'                -- 딜러 지정 시
GROUP BY d.dealer_nm, u.group_name, u.dept_nm, u.[name], o.common_tp_nm
ORDER BY d.dealer_nm, u.group_name, u.dept_nm, u.[name], o.common_tp_nm
```

### 6. 활동 진척률 (목록형, 실적/목표 — FULL OUTER JOIN으로 한쪽만 있는 행도 0으로 채움)
```sql
WITH ac AS (   -- 실적: DIM_CRM_ACT_TYPE.tp_grp_1 기준
    SELECT d.dealer_nm, u.group_name, u.dept_nm, u.[name], o.common_tp_nm,
        SUM(f.actual_cnt) AS ac_cnt
    FROM ktws.FCT_ACTIVITY_v2 AS f
        INNER JOIN ktws.DIM_CALENDAR_KTWS AS c ON f.act_dt_fr = c.[Date]
        INNER JOIN ktws.DIM_CRM_ACT_TYPE AS t ON f.tp_key = t.tp_key
        INNER JOIN ktws.DIM_CRM_ACT_TYPE_ORDER AS o ON t.common_tp_nm = o.common_tp_nm
        INNER JOIN ktws.DIM_MNG_USER AS u ON f.sc_key = u.sc_key
        INNER JOIN ktws.DIM_MNG_DEALER AS d ON u.dealer_key = d.dealer_key
    WHERE t.tp_grp_1 IN ('관계형성', '기회창출')
        AND c.[Year] = 2026 AND c.[MonthNumber] = 4
        AND d.dealer_nm IS NOT NULL AND LTRIM(RTRIM(d.dealer_nm)) <> ''
        AND (u.facade_sc_yn <> '창구SC' OR u.facade_sc_yn IS NULL)
        AND (u.[name] NOT IN ('고객지원팀', 'TOYOTA YM') OR u.[name] IS NULL)
    GROUP BY d.dealer_nm, u.group_name, u.dept_nm, u.[name], o.common_tp_nm
),
tgt AS (   -- 목표: DIM_CRM_ACT_TYPE_ORDER.tp_grp_1 기준 (실적과 필터 대상 테이블이 다름에 주의)
    SELECT d.dealer_nm, u.group_name, u.dept_nm, u.[name], o.common_tp_nm,
        SUM(f.target_cnt) AS tgt_cnt
    FROM ktws.FCT_CRM_TARGET_D AS f
        INNER JOIN ktws.DIM_CALENDAR_KTWS AS c ON f.daily_dt = c.[Date]
        INNER JOIN ktws.DIM_CRM_ACT_TYPE AS t ON f.type_cd = t.tp_key
        INNER JOIN ktws.DIM_CRM_ACT_TYPE_ORDER AS o ON t.common_tp_nm = o.common_tp_nm
        INNER JOIN ktws.DIM_MNG_USER AS u ON f.sc_key = u.sc_key
        INNER JOIN ktws.DIM_MNG_DEALER AS d ON u.dealer_key = d.dealer_key
    WHERE o.tp_grp_1 IN ('관계형성', '기회창출')
        AND c.[Year] = 2026 AND c.[MonthNumber] = 4
        AND d.dealer_nm IS NOT NULL AND LTRIM(RTRIM(d.dealer_nm)) <> ''
        AND (u.facade_sc_yn <> '창구SC' OR u.facade_sc_yn IS NULL)
        AND (u.[name] NOT IN ('고객지원팀', 'TOYOTA YM') OR u.[name] IS NULL)
    GROUP BY d.dealer_nm, u.group_name, u.dept_nm, u.[name], o.common_tp_nm
)
SELECT
    COALESCE(ac.dealer_nm, tgt.dealer_nm) AS dealer_nm,
    COALESCE(ac.group_name, tgt.group_name) AS group_name,
    COALESCE(ac.dept_nm, tgt.dept_nm) AS dept_nm,
    COALESCE(ac.[name], tgt.[name]) AS [name],
    COALESCE(ac.common_tp_nm, tgt.common_tp_nm) AS common_tp_nm,
    ISNULL(ac.ac_cnt, 0) AS act_mtd_ac_preOp,
    ISNULL(tgt.tgt_cnt, 0) AS act_mtd_target_preOp,
    CASE WHEN tgt.tgt_cnt IS NULL OR tgt.tgt_cnt = 0 THEN 1
         ELSE CAST(ISNULL(ac.ac_cnt, 0) AS DECIMAL(18,4)) / tgt.tgt_cnt END AS progress_act_mtd_preOp
FROM ac FULL OUTER JOIN tgt
    ON ac.dealer_nm = tgt.dealer_nm AND ac.group_name = tgt.group_name
    AND ac.dept_nm = tgt.dept_nm AND ac.[name] = tgt.[name] AND ac.common_tp_nm = tgt.common_tp_nm
ORDER BY dealer_nm, group_name, dept_nm, [name], common_tp_nm
```
주의: 실적(ac) CTE는 `DIM_CRM_ACT_TYPE.tp_grp_1`로 필터하고, 목표(tgt) CTE는 `DIM_CRM_ACT_TYPE_ORDER.tp_grp_1`로 필터한다 — GOLD 원본이 이렇게 다르게 작성돼 있으니 그대로 따를 것(둘 다 `common_tp_nm` 기준이라 실질값은 같지만, 조인 대상 테이블 별칭을 헷갈리지 말 것).

## 주의
- `CRM_ACT`류 원본 코드(P101, P110 등)를 직접 IN 리스트로 나열하지 말 것 — `DIM_CRM_ACT_TYPE.tp_grp_1 IN ('관계형성','기회창출')`로 표현하는 게 정답이다.
- `active_yn`은 'Y'/'N'이 아니라 **'재직'/'퇴사'** 문자열이다.
- 목록형(4/5/6번)은 `INNER JOIN`이 아니라 딜러만 `LEFT JOIN` 또는 `INNER JOIN`이다(GOLD 쿼리마다 다름 — 4/5번은 LEFT, 6번은 INNER) — 각 패턴 그대로 따를 것.
- 영업기회 전환율/계약 전환율 등 퍼널 하위 단계 지표는 이제 `영업기회_퍼널`/`계약` topic에 GOLD 쿼리가 있다(더 이상 DAX만 있는 게 아님) — 해당 topic을 참고할 것.
