# 차량재고 쿼리 규칙

## 테이블
`FCT_AVAIL_STOCK`(vehic_magic 단위)이 기준 테이블이다. 딜러명은 `DIM_MNG_DEALER`, 모델/차종/SFX는 `DIM_VEHIC_SPEC`.

**주의**: `dealer_key`→`DIM_MNG_DEALER`, `spec_key`→`DIM_VEHIC_SPEC` 조인은 관계설정 리스트에 공식적으로 문서화되어 있지 않다(컬럼명 규칙상 유추). 실제 값으로 조인이 되는지 결과를 확인한 뒤 사용을 권장한다.

## 예시
```sql
-- 딜러별 재고 대수
SELECT d.dealer_nm, COUNT(*) AS stock_cnt
FROM FCT_AVAIL_STOCK s
JOIN DIM_MNG_DEALER d ON d.dealer_key = s.dealer_key
GROUP BY d.dealer_nm
ORDER BY stock_cnt DESC

-- 배정상태별 재고 현황
SELECT al_status, progress, COUNT(*) AS cnt
FROM FCT_AVAIL_STOCK
GROUP BY al_status, progress
```
