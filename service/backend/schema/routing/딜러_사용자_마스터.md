# 딜러_사용자_마스터 쿼리 규칙

이 topic의 테이블들은 그 자체가 질문 대상이 되기보다, **다른 topic의 sc_key/dealer_key를 사람이 읽을 이름으로 바꿀 때** 함께 조인되는 경우가 많다.

## 테이블
- `DIM_MNG_DEALER`: 딜러 단위 마스터 (dealer_key 단위).
- `DIM_MNG_USER`: SC(사용자) 단위 마스터 (sc_key 단위) — 소속 지점(group_name)/딜러(dealer_nm)/부서(dept_nm) 정보를 함께 담고 있어 대부분의 "담당자명" 조회는 이 테이블 하나로 충분하다.
- `DIM_MNG_ACCESS_USER`: 리포트 권한관리(행 수준 보안) 전용 매핑 — 일반 업무 질문에는 거의 쓰이지 않는다.

## 예시
```sql
-- 딜러명으로 SC 목록 찾기 (이름 → 코드 역방향 조회)
SELECT sc_key, name, title, group_name
FROM DIM_MNG_USER
WHERE dealer_nm = '렉서스 강남' AND active_yn = 'Y'

-- 딜러별 소속 SC 인원수
SELECT dealer_nm, COUNT(*) AS sc_cnt
FROM DIM_MNG_USER
WHERE active_yn = 'Y'
GROUP BY dealer_nm
ORDER BY sc_cnt DESC
```

## 주의
- 매장/딜러 이름으로 다른 topic의 팩트 테이블을 필터링할 때는, 이름 문자열을 직접 넣지 말고 위 예시처럼 `DIM_MNG_USER`/`DIM_MNG_DEALER`에서 먼저 코드(sc_key/dealer_key)를 찾아 그 값으로 필터해야 한다.
