# 차량스펙_마스터 쿼리 규칙

## 테이블 선택 (계층 구조 — 필요한 세분화 수준에 맞는 것을 고를 것)
- 모델명만 필요하면 `DIM_VEHIC_SPEC_MDL` (mdl_key 단위, 가장 상위).
- 모델+차종명이 필요하면 `DIM_VEHIC_SPEC_VAR` (var_key 단위).
- 연식/SFX/그레이드/판매여부 등 상세 사양까지 필요하면 `DIM_VEHIC_SPEC` (spec_key 단위, 가장 상세).

세 테이블은 `model_key`/`var_key`로 계층 조인된다 (`DIM_VEHIC_SPEC.var_key` → `DIM_VEHIC_SPEC_VAR.var_key` → `DIM_VEHIC_SPEC_VAR.model_key` → `DIM_VEHIC_SPEC_MDL.mdl_key`).

## 예시
```sql
-- 현재 판매 중인 SFX 목록
SELECT model_nm, variant_nm, sfx_cd, grade
FROM DIM_VEHIC_SPEC
WHERE curr_sales_yn = 'Y'
ORDER BY model_nm, variant_nm

-- 모델별 판매 가능한 차종 수
SELECT v.model_nm, COUNT(*) AS variant_cnt
FROM DIM_VEHIC_SPEC_VAR v
GROUP BY v.model_nm
```
