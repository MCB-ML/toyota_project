# 담당고객 쿼리 규칙

## 테이블
`FCT_MNG_CUST_LIST`(cust_seq 단위)가 SC별 담당 고객 매핑을 담는다. 담당 SC명은 `DIM_MNG_USER`(mng_sc_key로 조인).

## 예시
```sql
-- SC별 담당 고객 수
SELECT u.name AS sc_name, COUNT(*) AS cust_cnt
FROM FCT_MNG_CUST_LIST c
JOIN DIM_MNG_USER u ON u.sc_key = c.mng_sc_key
GROUP BY u.name
ORDER BY cust_cnt DESC
```

## 주의
- 이 테이블은 고객-SC 매핑만 담고 있고 고객 상세 정보(이름, 연락처 등)는 없다 — 고객 상세가 필요하면 이 topic만으로는 답할 수 없으니 reject하거나 사용 가능한 범위(cust_seq, real_cust_seq, 담당 SC)만 답할 것.
