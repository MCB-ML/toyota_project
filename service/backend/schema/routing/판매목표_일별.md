# 판매목표_일별 쿼리 규칙

## 테이블
`FCT_SALES_TARGET_DAILY`(딜러+모델+일자 단위)가 기준 테이블이다. 딜러명은 `DIM_MNG_DEALER`, 모델명은 `DIM_VEHIC_SPEC_MDL`, 날짜 그룹핑은 `DIM_CALENDAR_KTWS`(dateby 기준).

## 핵심 규칙
- **`ac_trgt`=출고(딜리버리) 목표, `co_trgt`=계약 목표다 — 이름만 보면 반대로 헷갈리기 쉬우니 질문이 "출고 목표"인지 "계약 목표"인지 정확히 구분해서 컬럼을 고를 것.**
- 일일 단위 값이 필요하면 `ac_trgt_daily`/`co_trgt_daily`, 월 누적 값이 필요하면 `ac_trgt`/`co_trgt`.

## 예시
```sql
-- 딜러별 이번달 출고 목표 vs 계약 목표
SELECT d.dealer_nm, SUM(f.ac_trgt) AS delivery_target, SUM(f.co_trgt) AS contract_target
FROM ktws.FCT_SALES_TARGET_DAILY f
JOIN ktws.DIM_MNG_DEALER d ON d.dealer_key = f.dealer_key
WHERE f.dateby >= '2026-04-01' AND f.dateby < '2026-05-01'
GROUP BY d.dealer_nm
ORDER BY delivery_target DESC

-- 모델별 일일 계약 목표 추이
SELECT m.model_nm, f.dateby, f.co_trgt_daily
FROM ktws.FCT_SALES_TARGET_DAILY f
JOIN ktws.DIM_VEHIC_SPEC_MDL m ON m.mdl_key = f.model_key
ORDER BY f.dateby
```
