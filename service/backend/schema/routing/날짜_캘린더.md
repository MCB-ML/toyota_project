# 날짜_캘린더 쿼리 규칙

## 테이블
`DIM_CALENDAR_KTWS`(Date 단위) 하나뿐이다. 모든 FCT 테이블의 날짜 컬럼(act_dt_fr, contract_dt, daily_dt, monthly_dt, dateby, reply_date, meet_dt 등)이 이 테이블의 `Date`를 참조한다.

## 예시
```sql
-- 이번 분기 영업일수(공휴일 제외) 확인
SELECT COUNT(*) AS business_days
FROM DIM_CALENDAR_KTWS
WHERE QuarterNumber = 2 AND Year = 2026 AND kr_holiday <> '1'
  AND WeekdayNumber NOT IN (1, 7)  -- 주말 제외 (1=일요일, 7=토요일 등 실제 값 확인 필요)
```

## 주의
- 이 topic 자체가 질문 대상인 경우는 드물다 — 보통 다른 topic의 팩트 테이블과 날짜 컬럼으로 조인해 연/월/분기/주차 단위 그룹핑을 하기 위해 쓰인다.
- `WeekdayNumber`의 실제 요일 매핑(1이 월요일인지 일요일인지)은 값을 직접 확인한 뒤 사용할 것 — 정의서에 명시되어 있지 않다.
