# 계약 쿼리 규칙

이 topic의 쿼리 패턴은 `ktws_측정값_쿼리화.xlsx`(1-1, 1-2 시트)의 GOLD 쿼리에서 그대로 가져온 것이다 — 추측이 아니라 검증된 정답 SQL이므로, 아래 패턴과 다른 형태로 계약 건수/목표/전환율을 계산하지 말 것.

## 핵심 개념: "자격 리드(qualified_lead)"
계약 건수는 `FCT_CONTRACT_KTWS`를 단순 COUNT/SUM하지 않는다 — **영업기회_퍼널 topic과 동일한 "자격 리드" 판정을 통과한 리드에 연결된 계약만** 인정한다:
```sql
WITH qualified_lead AS (
    SELECT DISTINCT l.lead_key
    FROM ktws.FCT_LEAD AS l
    WHERE ( l.close_dt > @RefDate OR l.close_dt IS NULL OR l.last_retail_sales_dt IS NOT NULL )
      AND EXISTS (
          SELECT 1 FROM ktws.FCT_ACTIVITY_v2 AS a
              INNER JOIN ktws.DIM_CRM_ACT_TYPE AS at2 ON a.tp_key = at2.tp_key
          WHERE a.lead_key = l.lead_key
            AND at2.tp_grp_1 IN ('관계형성', '기회창출')
            AND a.act_result <> '부재중'
            AND a.lead_key IS NOT NULL
      )
)
```
계약 건수 계산은 `FCT_CONTRACT_KTWS.lead_key`를 이 `qualified_lead`와 INNER JOIN해서만 센다. **이 CTE 없이 `FCT_CONTRACT_KTWS`만 단순 집계하면 오답이다.**

`@RefDate` 기준일 계산 — 스칼라(1-1시트) GOLD는 `EOMONTH`를 두 번 감싸 쓰지만(`EOMONTH(EOMONTH(@MonthStart))`), `EOMONTH`는 이미 월말 날짜를 넣으면 같은 값을 돌려주는(멱등) 함수라 실질적으로는 **단일 EOMONTH와 같은 값**이다(둘 다 그 달의 말일). 다음달로 넘어가는 유예기간이 아니다 — 표기만 다를 뿐 목록형(1-2시트, `EOMONTH(DATEFROMPARTS(@Year,@MonthNumber,1))`)과 같은 날짜를 가리킨다:
```sql
DECLARE @MonthStart DATE = CAST(@YearMonth + '-01' AS DATE);
DECLARE @MaxDate DATE = EOMONTH(@MonthStart);
DECLARE @RefDate DATE = EOMONTH(@MaxDate);   -- = @MaxDate와 동일한 값(그 달의 말일)
```

## 반드시 포함해야 하는 필터 ("페이지 기본 조건")
```sql
AND (u.facade_sc_yn <> '창구SC' OR u.facade_sc_yn IS NULL)
AND (u.[name] NOT IN ('고객지원팀', 'TOYOTA YM') OR u.[name] IS NULL)
```
사용자가 명시한 조건(연월/딜러/BRAND/group_name/dept_nm/재직여부)은 그 위에 추가.

## GOLD 쿼리 패턴 (스칼라, 1-1시트)

### 1. 계약건수 (당월활동실적 기준 — 자격 리드에 연결된 계약만)
반드시 `SELECT` 또는 `WITH`로 시작할 것 — 아래처럼 날짜는 인라인 리터럴로 계산해서 넣는다(`DECLARE` 블록을 SQL 맨 앞에 붙이지 말 것, Fabric 실행기가 SELECT/WITH로 시작하지 않는 쿼리는 거부한다):
```sql
WITH mtd_dates AS (
    SELECT [Date] FROM ktws.DIM_CALENDAR_KTWS WHERE [Date] >= '2026-04-01' AND [Date] <= '2026-04-30'
),
filtered_users AS (
    SELECT D.sc_key
    FROM ktws.DIM_MNG_USER AS D
    INNER JOIN ktws.DIM_MNG_DEALER AS E ON D.dealer_key = E.dealer_key
    WHERE D.facade_sc_yn <> '창구SC'
      AND D.name NOT IN ('고객지원팀', 'TOYOTA YM')
      AND D.user_id NOT IN ('EXCLUDED_USER_ID', 'EXCLUDED_USER_ID', 'EXCLUDED_USER_ID', 'EXCLUDED_USER_ID', 'EXCLUDED_USER_ID', 'EXCLUDED_USER_ID')
      AND D.active_yn = '재직'
      AND E.dealer_nm = '렉서스 강남'
),
activity_leads AS (
    SELECT DISTINCT ACT.lead_key
    FROM ktws.FCT_ACTIVITY_v2 AS ACT
    INNER JOIN mtd_dates AS DT ON ACT.act_dt_fr = DT.[Date]
    INNER JOIN ktws.DIM_CRM_ACT_TYPE AS B ON ACT.tp_key = B.tp_key
    WHERE B.tp_grp_1 IN ('관계형성', '기회창출')
      AND (ACT.act_result <> '부재중' OR ACT.act_result IS NULL)
      AND ACT.lead_key IS NOT NULL
),
lead_pool AS (
    SELECT DISTINCT G.lead_key
    FROM ktws.FCT_LEAD AS G
    INNER JOIN mtd_dates AS DT ON G.lead_reg_dt = DT.[Date]
    INNER JOIN activity_leads AS A ON G.lead_key = A.lead_key
    WHERE (G.close_dt > '2026-04-30' OR G.close_dt IS NULL OR G.last_retail_sales_dt IS NOT NULL)
)
SELECT COALESCE(SUM(I.cnt), 0) AS contract_cnt
FROM ktws.FCT_CONTRACT_KTWS AS I
INNER JOIN mtd_dates AS DT ON I.contract_dt = DT.[Date]
INNER JOIN filtered_users AS U ON I.cn_sc_key = U.sc_key
INNER JOIN lead_pool AS L ON I.lead_key = L.lead_key
```
주의: 여기선 리드 등록일(`lead_reg_dt`)도 이번달 범위(`mtd_dates`)로 제한한다 — 영업기회_퍼널 topic의 "당월활동실적기준"과 조건이 100% 같지 않다(계약은 리드 등록일과 계약일 둘 다 이번달이어야 함을 암시).

### 2. 계약 목표
`FCT_CRM_TARGET_M`에서 `DIM_CRM_ACT_TYPE.common_tp_nm = '계약'`로 필터한다(영업기회 목표는 `tp_grp_1 IN ('관계형성','기회창출')`로 필터하는 것과 다름 — 계약은 활동유형 대분류가 아니라 `common_tp_nm` 자체가 '계약'인 것만 센다):
```sql
SELECT SUM(f.target_cnt) AS cntrct_funnel_mtd_target
FROM ktws.FCT_CRM_TARGET_M AS f
    INNER JOIN ktws.DIM_CALENDAR_KTWS AS c ON f.monthly_dt = c.[Date]
    INNER JOIN ktws.DIM_CRM_ACT_TYPE AS t ON f.tp_key = t.tp_key
    INNER JOIN ktws.DIM_MNG_USER AS u ON f.sc_key = u.sc_key
    INNER JOIN ktws.DIM_MNG_DEALER AS d ON u.dealer_key = d.dealer_key
WHERE t.common_tp_nm = '계약'
    AND c.[Year] = 2026 AND c.[MonthNumber] = 4
    AND (u.facade_sc_yn <> '창구SC' OR u.facade_sc_yn IS NULL)
    AND (u.[name] NOT IN ('고객지원팀', 'TOYOTA YM') OR u.[name] IS NULL)
    AND d.dealer_nm = '렉서스 강남'
```
(스칼라 1-1시트엔 "계약 목표" 단독 행이 없다 — 위 목록형 GOLD를 딜러/SC 슬라이서로 좁혀서 합계 낸 것. 스칼라로 물으면 위 쿼리를 그대로 SUM 형태로 쓰면 된다.)

### 3. 영업기회→계약 전환율 ("계약 전환률" = 계약건수 / 영업기회건수, 자격 리드 기준)
```sql
WITH qualified_lead AS (
    SELECT lead_key, cl_sc_key, tp_key
    FROM ktws.FCT_LEAD AS l
    WHERE ( l.close_dt > '2026-04-30' OR l.close_dt IS NULL OR l.last_retail_sales_dt IS NOT NULL )
        AND EXISTS (
            SELECT 1 FROM ktws.FCT_ACTIVITY_v2 AS a
                INNER JOIN ktws.DIM_CRM_ACT_TYPE AS at2 ON a.tp_key = at2.tp_key
            WHERE a.lead_key = l.lead_key AND at2.tp_grp_1 IN ('관계형성', '기회창출')
              AND a.act_result <> '부재중' AND a.lead_key IS NOT NULL
        )
),
lead AS (
    SELECT COUNT(DISTINCT l.lead_key) AS lead_cnt
    FROM ktws.FCT_LEAD AS l
        INNER JOIN ktws.DIM_CALENDAR_KTWS AS c ON l.lead_reg_dt = c.[Date]
        INNER JOIN ktws.DIM_MNG_USER AS u ON l.cl_sc_key = u.sc_key
        INNER JOIN ktws.DIM_MNG_DEALER AS d ON u.dealer_key = d.dealer_key
    WHERE c.[Year] = 2026 AND c.[MonthNumber] = 4
        AND ( l.close_dt > '2026-04-30' OR l.close_dt IS NULL OR l.last_retail_sales_dt IS NOT NULL )
        AND EXISTS (SELECT 1 FROM ktws.FCT_ACTIVITY_v2 AS a INNER JOIN ktws.DIM_CRM_ACT_TYPE AS at2 ON a.tp_key = at2.tp_key
                     WHERE a.lead_key = l.lead_key AND at2.tp_grp_1 IN ('관계형성', '기회창출') AND a.act_result <> '부재중')
        AND (u.facade_sc_yn <> '창구SC' OR u.facade_sc_yn IS NULL)
        AND (u.[name] NOT IN ('고객지원팀', 'TOYOTA YM') OR u.[name] IS NULL)
        AND d.dealer_nm = '렉서스 강남'
),
cntrct AS (
    SELECT SUM(f.cnt) AS cntrct_cnt
    FROM ktws.FCT_CONTRACT_KTWS AS f
        INNER JOIN ktws.DIM_CALENDAR_KTWS AS c ON f.contract_dt = c.[Date]
        INNER JOIN ktws.DIM_MNG_USER AS u ON f.cn_sc_key = u.sc_key
        INNER JOIN ktws.DIM_MNG_DEALER AS d ON u.dealer_key = d.dealer_key
        INNER JOIN (SELECT DISTINCT lead_key FROM qualified_lead) AS ql ON f.lead_key = ql.lead_key
    WHERE c.[Year] = 2026 AND c.[MonthNumber] = 4
        AND (u.facade_sc_yn <> '창구SC' OR u.facade_sc_yn IS NULL)
        AND (u.[name] NOT IN ('고객지원팀', 'TOYOTA YM') OR u.[name] IS NULL)
        AND d.dealer_nm = '렉서스 강남'
)
SELECT FORMAT(CAST(ISNULL(C.cntrct_cnt,0) AS DECIMAL(18,4)) / NULLIF(L.lead_cnt, 0), '0%') AS Percentage
FROM cntrct AS C CROSS JOIN lead AS L
```

## GOLD 쿼리 패턴 (목록형, 1-2시트)

### 4. 계약 실적 (딜러/부서/SC/활동유형카테고리별, 자격 리드 기준)
```sql
WITH qualified_lead AS (
    SELECT DISTINCT l.lead_key
    FROM ktws.FCT_LEAD AS l
    WHERE ( l.close_dt > EOMONTH(DATEFROMPARTS(2026, 4, 1)) OR l.close_dt IS NULL OR l.last_retail_sales_dt IS NOT NULL )
        AND EXISTS (
            SELECT 1 FROM ktws.FCT_ACTIVITY_v2 AS a
                INNER JOIN ktws.DIM_CRM_ACT_TYPE AS at2 ON a.tp_key = at2.tp_key
            WHERE a.lead_key = l.lead_key AND at2.tp_grp_1 IN ('관계형성', '기회창출')
              AND a.act_result <> '부재중' AND a.lead_key IS NOT NULL
        )
)
SELECT
    d.dealer_nm, u.group_name, u.dept_nm, u.[name], o.common_tp_nm,
    SUM(f.cnt) AS [cntrct_funnel_mtd]
FROM ktws.FCT_CONTRACT_KTWS AS f
    INNER JOIN ktws.DIM_CALENDAR_KTWS AS c ON f.contract_dt = c.[Date]
    INNER JOIN ktws.DIM_CRM_ACT_TYPE AS t ON f.tp_key = t.tp_key
    INNER JOIN ktws.DIM_CRM_ACT_TYPE_ORDER AS o ON t.common_tp_nm = o.common_tp_nm
    INNER JOIN ktws.DIM_MNG_USER AS u ON f.cn_sc_key = u.sc_key
    INNER JOIN ktws.DIM_MNG_DEALER AS d ON u.dealer_key = d.dealer_key
    INNER JOIN qualified_lead AS ql ON f.lead_key = ql.lead_key
WHERE (u.facade_sc_yn <> '창구SC' OR u.facade_sc_yn IS NULL)
    AND (u.[name] NOT IN ('고객지원팀', 'TOYOTA YM') OR u.[name] IS NULL)
--  AND c.[Year] = 2026 AND c.[MonthNumber] = 4   -- 연월 지정 시
GROUP BY d.dealer_nm, u.group_name, u.dept_nm, u.[name], o.common_tp_nm
ORDER BY d.dealer_nm, u.group_name, u.dept_nm, u.[name], o.common_tp_nm
```

### 5. 계약 목표 (딜러/부서/SC별 — activity 카테고리 무관, common_tp_nm='계약' 필터)
```sql
SELECT
    d.dealer_nm, u.group_name, u.dept_nm, u.[name],
    SUM(f.target_cnt) AS [cntrct_funnel_mtd_target]
FROM ktws.FCT_CRM_TARGET_M AS f
    INNER JOIN ktws.DIM_CALENDAR_KTWS AS c ON f.monthly_dt = c.[Date]
    INNER JOIN ktws.DIM_CRM_ACT_TYPE AS t ON f.tp_key = t.tp_key
    INNER JOIN ktws.DIM_MNG_USER AS u ON f.sc_key = u.sc_key
    INNER JOIN ktws.DIM_MNG_DEALER AS d ON u.dealer_key = d.dealer_key
WHERE t.common_tp_nm = '계약'
--  AND c.[Year] = 2026 AND c.[MonthNumber] = 4
    AND (u.facade_sc_yn <> '창구SC' OR u.facade_sc_yn IS NULL)
    AND (u.[name] NOT IN ('고객지원팀', 'TOYOTA YM') OR u.[name] IS NULL)
GROUP BY d.dealer_nm, u.group_name, u.dept_nm, u.[name]
ORDER BY d.dealer_nm, u.group_name, u.dept_nm, u.[name]
```
목표는 `common_tp_nm` 단위로 안 나오므로(계약이라는 카테고리 자체가 목표 단위) 목록에 `o.common_tp_nm` 컬럼이 없다 — 계약 실적(패턴4)과 조인해서 진행률을 낼 땐 `dealer_nm/group_name/dept_nm/name` 네 컬럼만으로 맞춘다.

### 6. 계약 전환률 (딜러/부서/SC/활동유형카테고리별, 영업기회→계약)
```sql
WITH qualified_lead AS (
    SELECT lead_key, cl_sc_key, tp_key
    FROM ktws.FCT_LEAD AS l
    WHERE ( l.close_dt > EOMONTH(DATEFROMPARTS(2026, 4, 1)) OR l.close_dt IS NULL OR l.last_retail_sales_dt IS NOT NULL )
        AND EXISTS (
            SELECT 1 FROM ktws.FCT_ACTIVITY_v2 AS a
                INNER JOIN ktws.DIM_CRM_ACT_TYPE AS at2 ON a.tp_key = at2.tp_key
            WHERE a.lead_key = l.lead_key AND at2.tp_grp_1 IN ('관계형성', '기회창출')
              AND a.act_result <> '부재중'
        )
),
lead AS (
    SELECT d.dealer_nm, u.group_name, u.dept_nm, u.[name], o.common_tp_nm,
        COUNT(DISTINCT l.lead_key) AS lead_cnt
    FROM ktws.FCT_LEAD AS l
        INNER JOIN ktws.DIM_CALENDAR_KTWS AS c ON l.lead_reg_dt = c.[Date]
        INNER JOIN ktws.DIM_CRM_ACT_TYPE AS t ON l.tp_key = t.tp_key
        INNER JOIN ktws.DIM_CRM_ACT_TYPE_ORDER AS o ON t.common_tp_nm = o.common_tp_nm
        INNER JOIN ktws.DIM_MNG_USER AS u ON l.cl_sc_key = u.sc_key
        INNER JOIN ktws.DIM_MNG_DEALER AS d ON u.dealer_key = d.dealer_key
    WHERE c.[Year] = 2026 AND c.[MonthNumber] = 4
        AND ( l.close_dt > EOMONTH(DATEFROMPARTS(2026, 4, 1)) OR l.close_dt IS NULL OR l.last_retail_sales_dt IS NOT NULL )
        AND EXISTS (SELECT 1 FROM ktws.FCT_ACTIVITY_v2 AS a INNER JOIN ktws.DIM_CRM_ACT_TYPE AS at2 ON a.tp_key = at2.tp_key
                     WHERE a.lead_key = l.lead_key AND at2.tp_grp_1 IN ('관계형성', '기회창출') AND a.act_result <> '부재중')
        AND (u.facade_sc_yn <> '창구SC' OR u.facade_sc_yn IS NULL)
        AND (u.[name] NOT IN ('고객지원팀', 'TOYOTA YM') OR u.[name] IS NULL)
    GROUP BY d.dealer_nm, u.group_name, u.dept_nm, u.[name], o.common_tp_nm
),
cntrct AS (
    SELECT d.dealer_nm, u.group_name, u.dept_nm, u.[name], o.common_tp_nm,
        SUM(f.cnt) AS cntrct_cnt
    FROM ktws.FCT_CONTRACT_KTWS AS f
        INNER JOIN ktws.DIM_CALENDAR_KTWS AS c ON f.contract_dt = c.[Date]
        INNER JOIN ktws.DIM_CRM_ACT_TYPE AS t ON f.tp_key = t.tp_key
        INNER JOIN ktws.DIM_CRM_ACT_TYPE_ORDER AS o ON t.common_tp_nm = o.common_tp_nm
        INNER JOIN ktws.DIM_MNG_USER AS u ON f.cn_sc_key = u.sc_key
        INNER JOIN ktws.DIM_MNG_DEALER AS d ON u.dealer_key = d.dealer_key
        INNER JOIN (SELECT DISTINCT lead_key FROM qualified_lead) AS ql ON f.lead_key = ql.lead_key
    WHERE c.[Year] = 2026 AND c.[MonthNumber] = 4
        AND (u.facade_sc_yn <> '창구SC' OR u.facade_sc_yn IS NULL)
        AND (u.[name] NOT IN ('고객지원팀', 'TOYOTA YM') OR u.[name] IS NULL)
    GROUP BY d.dealer_nm, u.group_name, u.dept_nm, u.[name], o.common_tp_nm
)
SELECT
    COALESCE(cntrct.dealer_nm, lead.dealer_nm) AS dealer_nm,
    COALESCE(cntrct.group_name, lead.group_name) AS group_name,
    COALESCE(cntrct.dept_nm, lead.dept_nm) AS dept_nm,
    COALESCE(cntrct.[name], lead.[name]) AS [name],
    COALESCE(cntrct.common_tp_nm, lead.common_tp_nm) AS common_tp_nm,
    ISNULL(cntrct.cntrct_cnt, 0) AS cntrct_funnel_mtd,
    ISNULL(lead.lead_cnt, 0) AS lead_funnel_mtd_preOp,
    CASE WHEN lead.lead_cnt IS NULL OR lead.lead_cnt = 0 THEN NULL
         ELSE CAST(ISNULL(cntrct.cntrct_cnt, 0) AS DECIMAL(18,4)) / lead.lead_cnt END AS cvr_cntrct_lead_mtd
FROM cntrct FULL OUTER JOIN lead
    ON cntrct.dealer_nm = lead.dealer_nm AND cntrct.group_name = lead.group_name
    AND cntrct.dept_nm = lead.dept_nm AND cntrct.[name] = lead.[name] AND cntrct.common_tp_nm = lead.common_tp_nm
ORDER BY dealer_nm, group_name, dept_nm, [name], common_tp_nm
```

## 주의
- **`FCT_CONTRACT_KTWS`를 단독으로 SUM/COUNT하면 안 된다** — 반드시 `qualified_lead`(자격 리드) 조인을 거쳐야 GOLD와 일치한다.
- 계약 목표는 `DIM_CRM_ACT_TYPE.common_tp_nm = '계약'` 필터를 쓴다 — 활동/영업기회 목표의 `tp_grp_1 IN ('관계형성','기회창출')` 필터와 다르다. 헷갈리지 말 것.
- `lead_time`/`sales_tp_key`(재구매유형)/`pma_yn`(PMA)/차종·SFX별 breakdown은 이번 GOLD 쿼리 업데이트에 포함되지 않았다 — 컬럼 스키마상으로는 존재하나 GOLD로 검증된 적 없으니 참고용으로만 쓸 것.
- `active_yn`은 'Y'/'N'이 아니라 **'재직'/'퇴사'** 문자열이다.

## GOLD 쿼리 패턴 (SC 출고 현황, 7시트)
"딜러사별/SC별 출고" 계열 질문은 위 계약/전환율 패턴과 다른 소스(`FCT_CONTRACT_KTWS`를 딜러·SC 단위로 직접 집계)를 쓴다. 헷갈리기 쉬운 3개를 구분할 것:
- **`pat_sc_group_count_matrix`** — "출고평균대수/누적취소율 등급"으로 SC를 나눈 뒤 그 등급대에 속하는 **SC 인원수(headcount)**. 출고 대수 자체가 아니라 "몇 명이 이 등급인지"를 센다 — "딜러사별 출고평균대수"를 이걸로 답하면 틀린다(과거 실수 사례).
- **`pat_sc_delivery_matrix`** — SC별 월평균 출고대수/누적취소율/연누적출고/PMA. **SC 단위**라 출력에 딜러 컬럼이 없다 — 딜러 단위로 묻는 질문엔 이 패턴을 딜러로 롤업할 방법이 없다(그래서 아래 패턴이 필요).
- **`pat_dealer_ytd_shipment_matrix`** — 딜러>전시장>부서>SC>PMA구분 계층의 **연누적 출고(실적)**. "딜러사별 출고(실적/현황/평균대수)"처럼 딜러 단위 출고량을 물으면 이 패턴이 정답 소스다 — 등급/재직 필터가 없다(GOLD 원본이 명시적으로 재직여부 영향을 안 받게 설계됨).
